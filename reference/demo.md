# Run the shiny demo (deprecated)

Use
[`run_shiny_demo`](https://jenswahl.github.io/stochvolTMB/reference/run_shiny_demo.md)
instead. Without arguments, `demo()` runs the shiny demo with a
deprecation warning. With arguments, it calls
[`demo`](https://rdrr.io/r/utils/demo.html), so `demo(topic)` still
works when stochvolTMB is attached.

## Usage

``` r
demo(...)
```

## Arguments

- ...:

  Passed to [`demo`](https://rdrr.io/r/utils/demo.html).

## Value

Called for its side effect.
