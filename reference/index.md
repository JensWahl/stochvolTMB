# Package index

## All functions

- [`demo()`](demo.md) : Run shiny demo
- [`estimate_parameters()`](estimate_parameters.md) : Estimate
  parameters for the stochastic volatility model
- [`logit()`](logit.md) : Logit transformation from the real line to
  (-1, 1).
- [`plot(`*`<stochvolTMB>`*`)`](plot.stochvolTMB.md) : Plot the
  estimated latent volatility process
- [`plot_diagnostics()`](plot_diagnostics.md) : Diagnostic plots based
  on one-step-ahead residuals
- [`plot_returns()`](plot_returns.md) : Plot returns with bands from the
  fitted model
- [`predict(`*`<stochvolTMB>`*`)`](predict.stochvolTMB.md) : Predict
  future returns and future volatilities
- [`residuals()`](residuals.md) : Calculate one-step-ahead (OSA)
  residuals for stochastic volatility model.
- [`sim_sv()`](sim_sv.md) : Simulate log-returns from a stochastic
  volatility model
- [`simulate_parameters()`](simulate_parameters.md) : Simulate from the
  asymptotic distribution of the parameter estimates
- [`spy`](spy.md) : Daily closing prices for the S&P500 from 2005 to
  2018.
- [`summary(`*`<stochvolTMB>`*`)`](summary.md) : Summary tables of model
  parameters
- [`summary(`*`<stochvolTMB_predict>`*`)`](summary.stochvolTMB_predict.md)
  : Calculate quantiles based on predictions from the predictive
  distribution
