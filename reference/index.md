# Package index

## All functions

- [`demo()`](https://jenswahl.github.io/stochvolTMB/reference/demo.md) :
  Run shiny demo
- [`estimate_parameters()`](https://jenswahl.github.io/stochvolTMB/reference/estimate_parameters.md)
  : Estimate parameters for the stochastic volatility model
- [`logit()`](https://jenswahl.github.io/stochvolTMB/reference/logit.md)
  : Logit transformation from the real line to (-1, 1).
- [`plot(`*`<stochvolTMB>`*`)`](https://jenswahl.github.io/stochvolTMB/reference/plot.stochvolTMB.md)
  : Plot the estimated latent volatility process
- [`plot_diagnostics()`](https://jenswahl.github.io/stochvolTMB/reference/plot_diagnostics.md)
  : Diagnostic plots based on one-step-ahead residuals
- [`plot_returns()`](https://jenswahl.github.io/stochvolTMB/reference/plot_returns.md)
  : Plot returns with bands from the fitted model
- [`predict(`*`<stochvolTMB>`*`)`](https://jenswahl.github.io/stochvolTMB/reference/predict.stochvolTMB.md)
  : Predict future returns and future volatilities
- [`residuals()`](https://jenswahl.github.io/stochvolTMB/reference/residuals.md)
  : Calculate one-step-ahead (OSA) residuals for stochastic volatility
  model.
- [`sim_sv()`](https://jenswahl.github.io/stochvolTMB/reference/sim_sv.md)
  : Simulate log-returns from a stochastic volatility model
- [`simulate_parameters()`](https://jenswahl.github.io/stochvolTMB/reference/simulate_parameters.md)
  : Simulate from the asymptotic distribution of the parameter estimates
- [`spy`](https://jenswahl.github.io/stochvolTMB/reference/spy.md) :
  Daily closing prices for the S&P500 from 2005 to 2018.
- [`summary(`*`<stochvolTMB>`*`)`](https://jenswahl.github.io/stochvolTMB/reference/summary.md)
  : Summary tables of model parameters
- [`summary(`*`<stochvolTMB_predict>`*`)`](https://jenswahl.github.io/stochvolTMB/reference/summary.stochvolTMB_predict.md)
  : Calculate quantiles based on predictions from the predictive
  distribution
